# Synthetic Cursor / Foundry demo workspace

This workspace contains no customer code or confidential data. Use the
`foundry-models` MCP server's `foundry_openai` (OpenAI Responses API) and
`foundry_claude` (Anthropic Messages API) tools for synthetic tasks.
Each tool runs inference on Microsoft Foundry; the outer Cursor agent still uses
Cursor's own model service. Never submit secrets or sensitive data to this experiment.

`.cursor/mcp.json` is generated by `scripts/Setup.ps1` with absolute paths for
your machine and is not committed. See `.cursor/mcp.example.json` for its shape.
